# PulseIQ – Multi-sensor Fusion and Machine Learning based Non-invasive Blood Glucose Monitoring Device

## Project Overview

PulseIQ is a software prototype designed to estimate blood glucose levels non-invasively using machine learning and multi-sensor data. The system aims to provide a painless and affordable alternative to traditional finger-prick glucose monitoring methods.

Currently, the project focuses on the software architecture and machine learning workflow. The wearable hardware component, consisting of PPG, GSR, and skin temperature sensors, is planned for future implementation. Sensor data is presently simulated to validate the complete end-to-end system.

## Features

* Personalized machine learning model for each user
* Real-time glucose prediction and trend analysis
* Risk assessment for high and low glucose conditions
* Interactive monitoring dashboard
* Firebase cloud database integration
* WebSocket-based real-time data streaming

## Technology Stack

* Frontend: React, TypeScript, Vite, Tailwind CSS
* Backend: Node.js, Express, WebSockets
* Machine Learning: Python, FastAPI, XGBoost, Scikit-Learn
* Database: Firebase Firestore
